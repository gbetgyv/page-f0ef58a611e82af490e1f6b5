操作说明与客户端下载

OpenConnectUs 采用通用机场订阅协议，无需独立安装官方 App。按下列步骤即可完成配置。客户端请从应用商店或开发者发布页获取，注意来源安全。

选择套餐并获取订阅

在本页对比套餐后通过官网完成订阅。登录用户中心复制 Clash、V2Ray 或 Surge 格式链接。请只使用 OpenConnectUs 官方网站提供的地址。

下载对应客户端

Windows 可用 Clash Verge 或 v2rayN；macOS 可用 ClashX Meta 或 Surge；iOS 常用 Shadowrocket、Stash；Android 可用 Clash Meta 或 NekoBox。路由器可配合 OpenClash 或 PassWall 导入。

导入订阅并连接节点

在客户端添加订阅 URL 并更新列表。优先选择延迟较低的 IPLC 或专线节点，开启系统代理或 TUN。国内网站可走直连分流以节省流量。

日常维护

定期更新订阅以获取最新节点。连接异常时先切换节点或检查本地网络。旗舰版与团队版可走优先工单通道。

节点与线路说明

节点覆盖北美、日本、新加坡、香港及欧洲等地，普通线路适合浏览与视频，IPLC 专线针对实时应用优化。我们持续巡检并替换拥塞线路，智能分流可让国内站点直连。具体可用节点以订阅更新后客户端列表为准。

常见问题

以下为使用 OpenConnectUs 机场订阅与客户端时的高频说明，建议收藏本页便于查阅。

OpenConnectUs 是什么？和普通 VPN 有何不同？

OpenConnectUs 提供机场订阅服务，通过 Clash、V2Ray 等协议接入全球节点，可按套餐灵活选择流量与设备数。相比单一 App 式 VPN，订阅方式便于多客户端、多设备共用，并支持分流与规则自定义，更适合同时需要流媒体、游戏与办公的用户。

如何从官网完成订阅并下载配置？

在套餐区选定方案后于官方网站下单，支付成功后进入用户中心复制订阅链接。再按本页「操作说明」下载对应系统客户端并导入该链接。请勿向第三方泄露订阅地址，以免流量被盗用。

支持哪些客户端？手机和电脑能一起用吗？

主流 Windows、macOS、iOS、Android 及部分路由器固件均可。同时在线设备数由套餐决定：基础版 3 台、旗舰版 5 台、团队版 20 台。同一订阅可在多端导入，注意不要超出设备上限。

流量如何计算？用完了怎么办？

按实际出境流量计量，套餐周期内不限速直至额度用尽。用尽后可等待下个计费周期重置，或升级至更高套餐。请在客户端或用户中心关注剩余流量，避免中途中断。

能否解锁流媒体？游戏延迟高怎么处理？

基础版提供基础解锁，旗舰版与团队版强调全节点原生流媒体。游戏请优先连接标注 IPLC 或游戏优化的节点，并关闭占用带宽的下载。若某节点异常，更新订阅后更换即可。

如何确认自己访问的是 OpenConnectUs 官网？

请核对浏览器地址栏为本站官方域名，并以本页套餐价格与说明为准。不要轻信来路不明的「低价机场」或代充。遇到登录或节点问题，优先通过站内工单联系，旗舰版享有优先响应。

可以在路由器上给全家使用吗？

可以。将订阅导入支持的路由插件后，局域网设备即可走代理。团队版流量与设备额度更适合该场景，也可按需做分应用或分设备分流，避免不必要的流量消耗。

官网提示：年付套餐相当于减免约两个月费用。需要游戏加速与流媒体全解锁的用户，建议直接选择 OpenConnectUs 旗舰版并按教程导入客户端。
